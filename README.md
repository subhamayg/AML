# This repository contains a sample of work done by me independently.

## Projects

* **[Label Noise](./LabelNoise/)**: Implementation of a transition matrix estimator and classification algorithms that are robust to label noise.
* **[Non-negative Matrix Factorization (NMF)](./NMF/)**: Implementation of Non-negative Matrix Factorization algorithms, including Multiplicative Update and Robust NMF (L1-Norm) on face datasets.
* **[Long Context Positional Bias](./LongContextPositionalBias/)**: Analysis of positional bias (primacy/recency effects) in long-context Large Language Models.
